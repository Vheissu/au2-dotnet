THE STARTER GUIDE

A stack you can follow.

A small working example, with clear places to add your own code.

One request, end to end.

The workspace sends a typed request to an ASP.NET Core endpoint. Entity Framework Core writes the change to SQLite and the response updates the view.

Aurelia view → Typed client → .NET endpoint → SQLite

Find your starting point

Build an interface
src/Starter.Web/src/routes/

Lazy-loaded routes, HTML templates, and plain TypeScript view models. Styles live in one CSS file.

Add a feature
src/Starter.Api/Features/

Keep endpoints and request contracts together. WorkItems is the example to follow.

Change the data
src/Starter.Api/Data/

The database context and migrations live here. Create a migration when the model changes.

Prove it works
tests/ · e2e/ · src/Starter.Web/test/

API integration tests use isolated SQLite databases. Browser tests exercise the running application.

Useful commands

npm run dev Start the API and frontend together
npm run check Lint, typecheck, test, and build
npm run test:e2e Run browser and accessibility checks
npm run api:types Regenerate TypeScript contracts from OpenAPI
npm run publish Build a single deployable .NET application

Before you make it public

The sample workspace is shared and has no sign-in. Add authentication and per-user authorization before storing private data. The README covers deployment, database migrations, and the starter’s boundaries.
